# 🚀 Crypto App

A modern and responsive cryptocurrency tracking application built with **React.js** and **Tailwind CSS**. This project allows users to browse real-time cryptocurrency market data, search for coins, switch between different market metrics, and visualize historical price trends through interactive charts.



## 🛠️ Technologies

- React.js
- Tailwind CSS
- Recharts
- React Loader Spinner
- CoinGecko API


### Desktop

- Responsive desktop layout
- Cryptocurrency table
- Interactive charts

### Mobile

- Mobile-friendly card layout
- Optimized chart modal
- Responsive navigation

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/dev-mohammad78/crypto-app.git
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```
